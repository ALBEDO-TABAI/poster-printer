# Palette datasets

`public/data/palettes.json` is built by `scripts/build-palettes.py` from:

| Dataset | Contents | Licence | Source |
|---|---|---|---|
| nice-color-palettes (Jam3 / Matt DesLauriers) | top ~1000 COLOURlovers palettes, 5 colours each | MIT (`nice-color-palettes.LICENSE.md`) | https://github.com/Jam3/nice-color-palettes |
| dictionary-of-colour-combinations (Matt DesLauriers) | Sanzo Wada, *A Dictionary of Color Combinations* (1933–34, public domain), 2–4 colour sets | MIT (`dictionary-of-colour-combinations.LICENSE.md`) | https://github.com/mattdesl/dictionary-of-colour-combinations |

Lightness / chroma / contrast / mood tags and palette indices were computed by us in CIE Lab; palette names in the UI are our own numbering.
